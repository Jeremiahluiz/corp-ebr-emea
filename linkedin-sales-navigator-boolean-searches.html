LinkedIn Sales Navigator Boolean Searches for GitHub Personas

Use each category and role level as a separate LinkedIn Sales Navigator Current job title search. Add the optional Keywords filter as a separate dimension when you want to narrow results toward GitHub, DevOps, platform engineering, application security, software supply chain, or AI relevance.

1. Choose a category and level

Copy one Boolean string into the Current job title filter. Run upper, middle, and front-line or IC searches separately.

2. Use OR between alternative titles

One profile is unlikely to hold every alternative title, so AND is not appropriate inside a job-title group.

3. Use AND between dimensions

Combine a Current job title group with the optional Keywords filter as separate Sales Navigator filters. This applies AND logic between the dimensions.

4. Keep the Boolean syntax intact

Preserve uppercase operators, quoted multi-word titles, and the surrounding parentheses when you paste.
