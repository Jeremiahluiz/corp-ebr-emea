Install the skill

Keep the package folder intact. The reference files contain required counting, attribution, layout, and validation rules.

1

Download and extract the ZIP

Download the package, then extract it. The archive contains one folder with this structure:

uk-team-weekly-update/
├── SKILL.md
            ├── PROMPT.md
            ├── README.md
            └── references/
                ├── workflow.md
                ├── page-layout.md
                └── validation.md
Keep the full folder. Do not copy SKILL.md alone. The skill depends on the reusable prompt and all three files in references/.
2

Verify Copilot CLI

Install Copilot CLI if needed, then sign in. Follow the official Copilot CLI installation guide.

copilot --version
copilot login
3

Copy the folder into your personal skills directory

macOS

mkdir -p ~/.copilot/skills
cp -R ~/Downloads/uk-team-weekly-update \
  ~/.copilot/skills/

Windows PowerShell

New-Item -ItemType Directory `
  -Force "$HOME\.copilot\skills"
Copy-Item -Recurse `
  "$HOME\Downloads\uk-team-weekly-update" `
  "$HOME\.copilot\skills\"

For more detail, see GitHub's official guide to adding Copilot skills.

4

Verify and enable

copilot skill list
copilot skill enable uk-team-weekly-update

Restart Copilot CLI or open a new session after enabling the skill.

Prepare the weekly update

The skill defaults to the previous completed Monday through Sunday in CET.

5

Confirm access

  • Revenue MCP access to the required Salesforce objects.
  • Access to the Salesforce report named JR Corp EMEA EBR- Activities This Week.
  • WorkIQ and Microsoft 365 access.
  • Access to the OneDrive or SharePoint prospecting tracker.
  • Google Chrome for opening and presenting the generated HTML page.

No credentials or access rights are included in the ZIP.

6

Prepare four short answers

The skill asks these questions one at a time:

  1. Is the prospecting tracker updated through the end of last week?
  2. Which prospecting campaigns ran last week?
  3. What worked or did not work?
  4. What help is needed from the sales team this week?

Keep campaign, learning, and help answers brief. They are speaking prompts for the presentation sections.

7

Run the skill

/uk-team-weekly-update

You can optionally include a completed reporting week, the tracker URL, or manual inputs with the command.

8

Let the skill reconcile the data

The workflow includes only Bouke Kingma's completed email and call Tasks associated with Accounts owned by the five fixed UK AEs. Every distinct Task counts, including repeated touches. Only identical Task IDs or confirmed identical Outreach activity IDs are deduplicated.

Contact activity follows the Contact's Account. Lead activity follows the Lead's associated Salesforce Account, not free-text company data. Unique Accounts come from the same final Task population and are deduplicated separately by Salesforce Account ID.

The activity result is checked against JR Corp EMEA EBR- Activities This Week after the report is set to last week's dates. If report execution is unavailable, the skill asks for an export or control total instead of inventing data.

9

Review and download the HTML page

The output is one self-contained .html file with two presentation sections. Section 1 covers campaigns, learnings, Accounts, meetings booked, completed activities, and the AE table. Section 2 covers current New Account Recommendations, common themes, up to three proposed actions, and a separate help section.

The page uses inline CSS and JavaScript only, supports scrolling and keyboard navigation, and prints as two clean pages. The skill opens the final local file in Google Chrome for visual review, then provides the actual HTML artifact as UK-Team-Prospecting-Update-[LAST-WEEK-START]-to-[LAST-WEEK-END].html.

Troubleshooting

Skill is not listedConfirm the full folder is under ~/.copilot/skills/, then start a new Copilot session.
Chrome does not openOpen the downloaded .html file manually in Google Chrome. The skill must still provide the artifact and state the limitation.
Metrics do not reconcileCheck the completed week, activity owner, Task status/type, Account ownership, and report date filter. Do not approve an unresolved total as confirmed.
